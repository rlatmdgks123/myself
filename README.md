## About Me
* 한국대학교에서 컴퓨터과학, 정보보안, 정보관리를 다중 전공하고 있습니다.
* 단순한 기능 구현을 넘어, 데이터의 무결성과 기밀성을 보장하는 시큐어 코딩(Secure Coding)과 제로 트러스트(Zero Trust) 아키텍처에 관심이 많습니다.
* 방대한 양의 데이터를 효율적으로 저장하고 안전하게 통제할 수 있는 정보 거버넌스(Information Governance) 및 데이터베이스 최적화를 연구합니다.
* 현재는 클라우드 환경에서의 자동화된 취약점 진단 파이프라인(DevSecOps) 구축을 학습하고 있습니다.

## Featured Projects

### SecureVault: 의료 데이터 암호화 및 접근 제어 API
* **설명:** 민감한 개인 의료 정보를 다루는 서비스에 적용할 수 있는 역할 기반 접근 제어(RBAC) 및 엔드투엔드 암호화 API 시스템
* **역할:** API 게이트웨이 설계, JWT 기반 인증 로직 구현, AES-256을 활용한 데이터베이스 암호화 적용
* **Tech:** `Go`, `PostgreSQL`, `Docker`, `Redis`
* **성과:** 모의 해킹(SQL Injection, XSS) 방어 테스트 통과 및 데이터 조회 응답 속도 20% 개선

### LogSentinel: AI 기반 네트워크 이상 징후 탐지 및 시각화 대시보드
* **설명:** 서버 로그와 트래픽 데이터를 실시간으로 수집하고 분석하여 비정상적인 접근 패턴을 관리자에게 경고하는 시스템
* **역할:** Elasticsearch를 활용한 로그 수집 파이프라인 구축, 파이썬 기반 머신러닝 이상 탐지 알고리즘 적용
* **Tech:** `Python`, `Elastic Stack (ELK)`, `AWS EC2`, `Scikit-learn`
* **성과:** 일일 100만 건 이상의 로그 처리 아키텍처 구성 및 관리자 모니터링 편의성 증대
